🛡 Budget & reserve

Keeps headroom free for your own interactive work. Only scheduled fires are ever skipped — a manual run always goes ahead — and if usage can't be read the guard lets everything through.

⏸ Pausing

A soft pause asks running jobs to wind down at their next safe point rather than killing them — a Claude run stops between tool calls, so nothing is left half-done and the session can be resumed. This is how long it waits before escalating.

🧵 Task sources

Repos whose bd backlog the scheduler may draw work from. Roots are only used by Discover on the Projects tab, and discovery registers projects as pending — a repo runs nothing until you activate it there.

Danger zone

Uninstall removes everything: launchd agent, data, and the tool itself. Type uninstall to confirm.
